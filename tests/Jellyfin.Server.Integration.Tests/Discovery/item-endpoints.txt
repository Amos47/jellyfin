# Fork: discovery. Every API endpoint whose 200 response hands out BaseItemDto (directly, in a QueryResult or inside
# another DTO), checked by DiscoveryContractTests.ItemEndpoints_Tripwire. When upstream adds one, the tripwire fails:
# classify it here and, if it lists library items, add a hiding test.
#
# Format: METHOD /path  # class: note. Only the text before '#' is compared.
# Classes:
#   hidden      lists library items; discovery films and their trailers are left out (test named)
#   by-id       the item asked for, or its own ancestors, extras, parts or by-id links; a discovery film resolves by
#               design (detail pages, trailer queue, player refetch)
#   by-name     one genre/studio/person/artist/year item by name; its counts use guarded queries
#   not-movies  only music, shows, channels or Live TV items, never a Movie or a Trailer
#   other       not an item list (sessions, sign-in)
#
# Not in this list because they don't return BaseItemDto, but covered anyway: /Search/Hints (DiscoveryGuardTests
# for films; Genres_Studios_Persons_Exclude for people credited only on discovery films, which are left out with a
# user token; with an API key a search still leaks them and the films' trailers, a known gap), /Items/Counts
# (DiscoveryGuardTests), /Items/Filters, /Items/Filters2 (DiscoveryContractTests.Filters_And_Years_Exclude).

GET /Items  # hidden: DiscoveryGuardTests (recursive, parentId of the folder, search), Collections_Exclude, Trailers_Excludes; Person items credited only on discovery films are left out too, with or without a user and with a user's searchTerm (Genres_Studios_Persons_Exclude; shared cast stays, Persons_SharedCast_Listed); known gap: an API-key searchTerm loads unguarded search-provider ids by explicit ids, so it still lists them and the films' trailers; explicit ids bypass the guard by ruling (Items_ByIds_ReturnsDiscovery)
GET /Items/Latest  # hidden: Latest_Excludes
GET /Items/Root  # by-id: the user's root folder
GET /Items/Suggestions  # hidden: Suggestions_Excludes
GET /Items/{itemId}  # by-id: the discovery film's detail page
GET /Items/{itemId}/Ancestors  # by-id: an item's own parents (a discovery film's are the hidden folder and the root)
GET /Items/{itemId}/Collections  # by-id: the box sets holding the item; box sets never hold discovery films (Collections_Exclude)
GET /Items/{itemId}/InstantMix  # not-movies: songs
GET /Items/{itemId}/Intros  # by-id: intros come only from plugin intro providers (none built in); their library queries are guarded
GET /Items/{itemId}/LocalTrailers  # by-id: the item's own trailers, by owner id (a discovery film's page shows its trailer by design)
GET /Items/{itemId}/Similar  # hidden: Similar_Excludes
GET /Items/{itemId}/SpecialFeatures  # by-id: the item's own extras, by owner id
GET /Items/{itemId}/ThemeMedia  # by-id: the item's own theme extras
GET /Items/{itemId}/ThemeSongs  # by-id: the item's own theme extras
GET /Items/{itemId}/ThemeVideos  # by-id: the item's own theme extras
GET /Library/MediaFolders  # other: admin only; lists the root's virtual children, so the empty discovery folder appears, flagged hidden (shown with no isHidden filter and with isHidden=true, not with isHidden=false); never its films (MediaFolders_ListsFolderOnlyAsHidden).
